# AppLock themes

Lock screen theme images used by the AppLock app (ready themes). Served read-only via raw.githubusercontent.com.

- `<pack>/bg/` full screen backgrounds (1080x2400 WebP)
- `<pack>/thumb/` grid thumbnails (360x800 WebP)
- `<pack>/preview/` thumbnails with the key pack drawn on (keypad themes, 360x800 WebP)
- `<pack>/keys/` PIN key and pattern node images (256x256 WebP, `_push` = pressed/selected)

Files are referenced by tag; do not rewrite or delete tagged files.
